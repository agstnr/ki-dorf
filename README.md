# KI-Dorf

Begleitspiel zum zweitägigen KI-Seminar von Aisha Gstöttner.

Das Dorf ist eine einzige HTML-Datei (`index.html`). Sie läuft ohne Server, ohne Konten, ohne Tracking und ohne Internet.

- Inhalte (Häuser, Aufgaben, Tipps) stehen als Datenliste am Anfang des Skripts.
- Der Spielstand ist ein Code zum Kopieren. Er enthält keine Namen oder Eingaben.
- Enthalten: three.js r128 (MIT-Lizenz) und die Schriften Fredoka und Nunito (SIL Open Font License 1.1).

Alle Beispiele in den Aufgaben sind erfunden. Tool-abhängige Angaben haben den Stand Oktober 2026 und werden vor dem Seminar gegen die offiziellen Seiten der Anbieter geprüft.
